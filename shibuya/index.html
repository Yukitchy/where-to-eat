Good to know

  • Hours and days off can change. Check the listing on the map before you go.
  • Gyukatsu Motomura usually has a line. The nearby Bunten branch is run by the same shop.
  • Kaikaya is evenings only and closed on Wednesdays.
  • Yasubee is open until 03:00 Monday to Saturday, the latest on this list.
